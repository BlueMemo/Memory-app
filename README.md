# Memory App (working name)

A flashcard website built around visualization and memory routes. See `CLAUDE.md` for how the code is
organized and the roadmap.

## Getting started

Requires Node.js 24 or later.

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Checks

```bash
npm test
npm run typecheck
npm run lint
npm run build
```
